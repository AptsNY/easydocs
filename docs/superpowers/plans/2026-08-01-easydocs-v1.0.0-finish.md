PDF *look* right).

## Execution model

One fresh agent per task, dispatched with only the context that task needs. The main session reviews
each agent's output, folds it in, and dispatches the next. This keeps the orchestrating context small
enough to stay accurate across the whole run.

## Exit gate

repo.
